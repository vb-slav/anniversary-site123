# Наша годовщина — сайт-поздравление

Готовый статический сайт на HTML, CSS и JavaScript. Не требует сервера, сборки или API. Адаптирован для мобильных экранов, включая iPhone 14 (390 × 844 CSS px).

## Уже добавлено

- Ваша фотография: `assets/our-photo.jpg`.
- Ваш музыкальный трек: `assets/our-song.mp3`.
- Запуск музыки привязан к нажатию «Да», чтобы Safari на iPhone мог разрешить воспроизведение после действия пользователя.
- На странице с фотографией сохранены пропорции исходного вертикального снимка, поэтому пара не обрезается по бокам/сверху.

## Локальный просмотр

Открой `index.html` в браузере. Для проверки через локальный сервер можно выполнить в этой папке:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000`.

## Публикация через GitHub Pages

1. Создай новый репозиторий на GitHub.
2. Загрузи в корень репозитория все файлы и папку `assets`.
3. Открой **Settings → Pages**.
4. В **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, затем нажми **Save**.
6. После публикации GitHub покажет адрес сайта в разделе Pages. Открой его с iPhone или любого другого устройства.

## Важно о приватности и музыке

Если репозиторий публичный, фотография и MP3 тоже будут доступны публично. Для личного семейного сайта это может быть нежелательно — можно сделать приватный репозиторий, но доступность GitHub Pages для приватных репозиториев зависит от тарифного плана и настроек GitHub. Также проверь, что у тебя есть право публиковать выбранный музыкальный файл.

На iPhone Safari может не разрешить автоматическое воспроизведение в отдельных настройках браузера/устройства. В этом случае на странице появится кнопка ▶ для ручного запуска.
