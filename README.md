# Наша годовщина — персональный сайт-подарок

Статический сайт на HTML, CSS и JavaScript. Не требует собственного сервера или сборки. Адаптирован для мобильных экранов, включая iPhone 14 (390 × 844 CSS px), и для настольных браузеров.

## Что есть на сайте

- Романтическая страница-письмо с обращением «Дорогая жина!» и вопросом «Ты выйдешь за меня вновь?».
- Страница после ответа «Да» с вашей фотографией, песней Tony Tonite — «Бомба» и дополненным текстом: «Я очень счастлив, что ты моя половинка!».
- Купоны на подарки с подробным описанием при нажатии.
- После нажатия «Забираю ♥» отправляется письмо с выбранным купоном на `vladbudr@yandex.ru`.
- При выборе «Нет» открывается отдельная страница со ссылкой на Госуслуги.
- Мягкие анимации, бумажная текстура, декоративные лепестки и альбомная рамка для фото. Учтена настройка `prefers-reduced-motion`.

## Уведомления о выборе подарка

Для отправки писем используется FormSubmit — внешний сервис обработки форм. Сайт размещён на GitHub Pages и не имеет собственного сервера, поэтому браузер отправляет уведомление через этот сервис.

**Однократная активация перед первым использованием:**

1. Опубликуй обновлённый сайт на GitHub Pages.
2. Открой опубликованный сайт и пройди сценарий «Да» → «Выбрать подарок».
3. Открой любой купон и нажми «Забираю ♥» (это можно сделать самому для проверки).
4. FormSubmit отправит на `vladbudr@yandex.ru` письмо с просьбой подтвердить адрес. Открой его и перейди по ссылке активации.
5. После активации следующие подтверждённые выборы купонов будут приходить на эту почту.

Первое тестовое сообщение может сохраниться у FormSubmit до подтверждения адреса. После подтверждения проверь папку «Спам», если письмо с выбором не появилось во «Входящих».

**Важно о видимости адреса:** сейчас адрес получателя указан в `script.js` в URL FormSubmit. В публичном GitHub-репозитории его смогут увидеть посетители исходного кода. После первичной активации FormSubmit позволяет заменить адрес в URL на выданный сервисом случайный идентификатор (режим скрытого адреса); это лучше сделать, если не хочется публиковать адрес в исходниках.

При отправке передаются только название и описание выбранного купона, дата/время выбора и URL сайта. Почтовый пароль или ключ от Яндекса в коде не используется.

## Локальный просмотр

Открой `index.html` в браузере. Для корректной проверки файлов можно поднять локальный сервер из этой папки:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000`.

## Публикация на GitHub Pages

1. Загрузи в корень репозитория `index.html`, `styles.css`, `script.js`, `README.md` и папку `assets`.
2. Открой **Settings → Pages**.
3. В **Build and deployment** выбери **Deploy from a branch**.
4. Укажи ветку `main` и папку `/ (root)`, затем нажми **Save**.
5. После публикации GitHub покажет URL сайта в разделе Pages.

Если сайт уже опубликован, замени `index.html`, `styles.css`, `script.js` и `README.md` в корне репозитория. Папку `assets` повторно загружать не нужно, если в ней уже лежат `our-photo.jpg` и `our-song.mp3`.

## Музыка

MP3 подключён через `src="./assets/our-song.mp3"`. Запуск `audio.play()` вызывается прямо внутри обработчика нажатия «Да», что помогает пройти ограничения браузеров на автозапуск. Если компьютерный браузер всё равно заблокирует автоматическое воспроизведение, на странице останется кнопка ▶ для ручного старта.

На iPhone Safari автоматический звук также может быть ограничен настройками устройства или браузера.

## Состав проекта

```text

```

Если репозиторий публичный, фотография и MP3 будут доступны всем, у кого есть ссылка на файлы в репозитории. Учитывай это перед публикацией.
